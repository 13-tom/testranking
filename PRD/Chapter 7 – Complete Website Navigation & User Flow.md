# Chapter 7 – Complete Website Navigation & User Flow

**Project:** Board Ranking

**Document Type:** Product Requirement Document (PRD)

**Version:** 1.0

---

# 1. Introduction

This chapter defines the complete navigation structure of Board Ranking Release 1.

It explains how a user moves through the website from the moment they visit the homepage until they complete a test and view their analysis.

The objective is to create a simple, predictable, and student-friendly navigation experience.

Every page must have a clear purpose and guide the student toward learning.

---

# 2. Website Structure

Board Ranking consists of three main sections:

### 1. Public Website

Accessible without login.

Purpose:

Introduce the platform and encourage registration.

---

### 2. Student Portal

Accessible only after login.

Purpose:

Practice, analytics, rankings, and profile management.

---

### 3. Admin Portal

Accessible only to administrators.

Purpose:

Manage the platform.

# 21. Website Navigation Rules

Every page must follow these principles:

* Maximum three clicks to reach any major feature.
* Navigation must remain consistent.
* Back navigation should always work.
* Students should never feel lost.
* Dashboard should always be one click away.

---

# 22. Page Loading Behaviour

Every page should display:

* Skeleton Loader
* Loading Indicator
* Error State
* Empty State (where applicable)

Students should never see a blank screen.

---

# 23. Error Pages

The website should include:

404 Page

500 Error Page

No Internet Screen

Maintenance Mode

Each page should guide the student back to the main platform.

---

# 24. Mobile Responsiveness

Although Release 1 is desktop-first, every page should remain usable on tablets and mobile browsers.

Navigation should adapt without breaking functionality.

---

# CTO Statement

A good product is not defined by the number of pages it has.

It is defined by how naturally users move between those pages.

Every page in Board Ranking should reduce confusion, encourage learning, and help students reach their next study session with the fewest possible clicks.

Navigation should feel invisible—the student should focus on learning, not on finding features.
